# **App Name**: FriendVerse

## Core Features:

- User Profiles: Users can create profiles with avatars and bios.
- Friend Requests: Send, accept, or decline friend requests. Users can view their friends list.
- Profile Pic Generator: Generative AI tool to create custom profile pictures.
- Status Display: Display the online/offline status of friends.
- Newsfeed: Display list of Friends status and posts, sorted by time.
- User Search: Users can search the database to find each other and connect
- User reporting: Allow users to report inappropriate behavior to the administrator

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to convey creativity and community.
- Background color: Very light purple (#F3E5F5) to provide a gentle, non-distracting backdrop.
- Accent color: Pink (#E91E63) for interactive elements and highlights to draw attention.
- Font pairing: 'Poppins' (sans-serif) for headlines and short text; 'PT Sans' (sans-serif) for body.
- Use a consistent set of outlined icons for a clean and modern look.
- Card-based layout for content blocks, ensuring readability and easy navigation.
- Subtle transitions and animations to provide feedback and enhance user experience.
